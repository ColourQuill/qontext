# Qontext
Utility software that includes/will include features such as:

- File formats as structs (currently only TTF is implemented)
- File reading and writing (Such as directly reading a TTF file and generating a raw and easier to use struct based on the file)

- Single Glyph SDF/PSDF/MSDF/MTSDF Generation
- Font Atlas SDF/PSDF/MSDF/MTSDF Generation
